# 학습실 LR1 · LR2

2026-09-14 기준으로 영어 라이팅과 YouTube 학습을 구현했다. 전체 확장 범위는 [명세서](LEARNING_ROOM_SPEC.md), 구현 계약은 [LR1 계획](superpowers/plans/2026-09-14-learning-room-lr1.md), [LR2 계획](superpowers/plans/2026-09-14-learning-room-lr2.md)을 따른다.

## YouTube로 공부하기

`/learn`의 영상 링크 입력에 한 줄씩 최대 20개를 붙여 넣는다. 같은 영상은 기존 자료를 재사용하고 잘못된 링크는 항목별로 안내한다. Google 계정 연결은 필요 없다. 저장한 영상을 선택하면 `/learn/items/{id}`에서 공식 플레이어가 열린다.

- 마지막 저장 위치에서 재생하고, 지원 배속과 A–B 반복을 사용할 수 있다. 영상의 재생 위치와 실제 경과한 학습 시간은 별도로 기록한다. 탐색으로 건너뛴 구간은 시청 구간으로 인정하지 않는다.
- 일시 정지·종료·화면 숨김 때 영상을 멈추고 마지막 위치를 동기화한다. 플레이어가 정지·버퍼링 중이면 시청 활동은 멈춘다. 동시에 글을 쓰는 경우에는 같은 세션의 글쓰기 시간이 이어질 수 있다.
- 영상 제목은 처음에는 영상 ID로 표시한다. **영상 제목과 보관 설정**에서 원하는 제목, 즐겨찾기, 보관 여부를 정할 수 있다.
- **메모**에서 현재 영상 시각과 함께 글을 저장한다. 저장한 시각을 누르면 그 위치로 이동한다. **시청 구간**에는 PaceOn 안에서 확인한 구간을 표시한다.
- **자막 · AI 원문**에서 TXT/SRT/VTT 파일(1MiB 이하)이나 텍스트를 넣고, AI에 사용할 부분을 선택해 저장한다. 저장 원문은 100,000자, 선택 부분은 12,000자 이하다. 자동 자막 수집은 하지 않는다.
- AI 질문과 정리는 선택한 자막, 최근 메모 20개, 저장된 대화를 근거로 한다. 요청 전체는 20,000자 이하여야 한다. 자막이 없으면 메모와 대화만 참고하며, 영상 전체를 시청한 것처럼 요약하지 않는다.
- API에서 불러온 Google 목록 제목은 화면에서만 사용한다. 선택 저장은 영상 URL만 전달하므로 연결 해제 뒤 개인 학습 기록에 외부 계정 정보가 섞이지 않는다.

**YouTube 계정 연결**은 재생목록·구독 채널의 영상 선택을 위한 별도 기능이다. 서버 코드와 제공자 fixture 검증은 완료했지만 Google 프로젝트가 없어 실제 계정 동의는 아직 검증하지 않았다. [Google 프로젝트 및 OAuth 설정 안내](YOUTUBE_SETUP.md)에 따라 준비한다. 계정 연결로 광고 제거·Premium 인증·YouTube 전체 시청 기록 동기화를 제공하지 않는다.

## 사용 방법

1. 로그인 후 `/learn` 또는 메뉴의 **학습실**을 연다.
2. **새 글 쓰기**를 누르거나 최근 공간을 선택한다. 글을 쓰면 학습 시간이 시작된다.
3. 초안은 기기에 즉시, 서버에 약 3초 뒤 저장한다. 다른 기기의 수정과 충돌하면 두 초안을 확인하고 선택한다.
4. **AI에게 보내기**로 원문을 저장하고 첨삭·표현·예문·다음 연습을 받는다.
5. **일시 정지 / 학습 재개 / 학습 종료**로 시간을 관리한다. **이번 학습 정리하기**는 해당 세션에서 AI에 보낸 대화를 요약한다. 보내지 않은 초안은 포함하지 않는다.

종료한 공간에서도 초안과 노트를 계속 볼 수 있다. 다시 쓰면 새 세션을 시작한다. 다른 탭이나 기기에서 진행 중이면 **이 기기로 학습 옮기기**를 눌러야 계측 소유권이 바뀐다. 화면 숨김·1분 무활동은 자동 정지하며, 사용자가 직접 정지한 세션은 명시적으로 재개해야 한다.

## 실행 및 검사

기존 Supabase Local과 Next.js를 사용한다. LR1 마이그레이션 두 개와 LR2의 `20260920000000_learning_videos.sql`, `20260921000000_youtube_connections.sql`, `20260922000000_video_source_validation.sql`, `20260923000000_video_recency.sql`을 `supabase migration up --local`로 적용하고 `pnpm db:types`로 타입을 생성한다. 데이터 초기화는 필요 없다.

웹 `AI_ENABLED=true`, Worker의 기존 `AI_ENABLED`, `OPENAI_API_KEY`, `OPENAI_MODEL` 설정을 사용한다. 키는 Worker에만 두며 새 브라우저 키는 필요 없다. Worker 재빌드:

```powershell
docker compose --env-file services/ai-worker/.env -f docker/docker-compose.yml up -d --build ai-worker
```

검사 명령:

```powershell
pnpm test
pnpm lint
pnpm typecheck
pnpm build
pnpm db:test
pnpm db:types:check
pnpm test:learning:integration
```

통합 검사는 빌드된 웹앱을 임시 포트에서 실행하고 테스트 계정을 생성·삭제한다. 큐 접수까지 검증하므로 실제 Worker가 실행 중이면 테스트 문장이 AI에 전달될 수 있다. 비용 없는 반복 실행에는 별도 로컬 테스트 환경에서 Worker를 정지한다. 완료 출력·소유권·재시도는 pgTAP와 Worker 단위 테스트로 별도 검증한다.

## 현재 범위와 제한

- AI는 저장된 작업을 처리하고 화면이 결과를 주기적으로 확인한다. 토큰 스트리밍·생성 취소는 아직 없다.
- 메시지는 8,000자, 요청 문맥은 20,000자다. 긴 대화는 자동으로 잘라 분석하지 않고 한도 오류로 안내한다. 새 공간에서 이어서 작성할 수 있다.
- 자동 AI 전송은 하지 않는다. 요약도 버튼을 눌러 요청한다. AI를 끄거나 제공자 장애가 나도 초안과 세션 기록을 보관한다.
- 학습 시간은 서버 시간으로 확정한다. 네트워크 단절·브라우저 종료 뒤의 미확인 시간을 임의로 추가하지 않는다. 세션의 시간대와 UTC 활동 구간을 보존한다.
- 현재 열린 화면에서 초안을 기기에 보관하지만, 오프라인에서 앱을 새로 여는 기능은 보장하지 않는다. PWA는 LR5다.
- 스피킹·쉐도잉은 LR3, 표현 복습·기존 통계 통합은 LR4다. 학습실 기록을 기존 도서 페이지 진도에 합산하지 않는다.
- 공간 이름 변경·보관·삭제 UI, 운영 비용 경보, 스트리밍과 부분 응답 복원은 후속 작업이다.

LR1 검증: 웹/스케줄러 156개, Worker 33개, DB 255개 검사 및 실제 Auth/API 통합 검사. 임시 계정으로 실제 GPT 첨삭·요약 저장, 초안 새로고침 복원, 종료/이어하기, 탭 간 소유권 이전, 390px 모바일 및 390×420 짧은 화면 입력을 확인했다.

LR2 브라우저 검증: 임시 계정으로 실제 YouTube 공식 예제 영상의 재생·저장 위치 복원, 2배속의 별도 경과 시간, 약 4초 A–B 반복 구간 저장, 마지막 위치 저장 후 수동 정지·종료·탭 숨김 정지를 확인했다. 자막 원문 선택·메모 저장·실제 GPT 답변과 한국어 요약도 확인했다. 390px 홈에서 최근 영상 이어하기와 썸네일, 짧은 화면 입력을 확인했다. 실제 iOS/Android 기기의 가상 키보드·Google 동의·Premium 적용 여부 검증은 별도 필요하다.

LR2 최종 검사: 웹/스케줄러 171개, Worker 35개, DB 317개 및 LR1/LR2 Auth/API 통합 검사 통과. Lint·TypeScript 빌드·DB 타입 일치도 확인했다.
