# 영어 학습 LR1 · LR2 · LR3

2026-09-14 기준으로 영어 쓰기, YouTube 학습, 말하기·쉐도잉을 구현했다. 전체 확장 범위는 [명세서](LEARNING_ROOM_SPEC.md), 구현 계약은 [LR1 계획](superpowers/plans/2026-09-14-learning-room-lr1.md), [LR2 계획](superpowers/plans/2026-09-14-learning-room-lr2.md), [LR3 계획](superpowers/plans/2026-09-14-lr3-speech.md), 영역 분리 설계는 [영어 학습 영역 분리 설계](superpowers/specs/2026-09-14-learning-areas-design.md)를 따른다.

## 메뉴와 이어하기

제목 바로 아래에서 **듣기 / 말하기 / 쓰기**를 선택한다. **단어장 / 공통 복습**은 보조 링크다. 영역의 시작 행동 다음에는 그 영역의 이어하기를 보여 준다. PC는 최대 3개, 모바일은 최근 1개를 먼저 보여 주고 **이어하기 더 보기**로 나머지를 펼친다. URL과 마지막 영역 기억은 기존 값을 유지한다.

## 영역

영어 학습은 듣기·말하기·쓰기 세 영역 탭(`/learn/listening`, `/learn/speaking`, `/learn/writing`)으로 나뉜다. 공간마다 종류(`kind`)를 저장하며 한 번 정해지면 바꿀 수 없다. `/learn`은 마지막으로 본 탭으로 이동하고, 저장된 값이 없거나 잘못됐으면 듣기으로 이동한다.

| 주소 | 종류 | 표시 기능 |
| --- | --- | --- |
| `/learn/items/[id]` | 듣기 | 타이머, 영상, 메모, 자막, 질문, 쉐도잉 |
| `/learn/[id]` | 말하기 | 타이머, 말하기 패널 |
| `/learn/[id]` | 쓰기 | 타이머, 글쓰기, AI 첨삭, 정리. 기존 음성 기록이 있으면 접힌 **이전 말하기 기록**(읽기 전용) |

듣기 공간을 `/learn/[id]`로 열면 `/learn/items/[id]`로 옮긴다. 영역을 나누기 전에 만든 공간은 아래 규칙을 위에서부터 먼저 맞는 것으로 분류했다.

| 순서 | 조건 | 결과 |
| --- | --- | --- |
| 1 | 저장된 영상이 있음 | 듣기 |
| 2 | AI에 보낸 메시지가 있거나 초안이 있음 | 쓰기(음성 기록이 섞여 있어도) |
| 3 | 저장된 말하기 기록이 있음 | 말하기 |
| 4 | 기록 없음, 제목 "나의 영어 말하기" | 말하기 |
| 5 | 그 외 | 쓰기 |

쓰기 공간에 영역을 나누기 전 녹음이 남아 있으면 **이전 말하기 기록**을 접힌 목록으로 보여준다. 인식문·피드백 보기와 녹음 재생만 되며, 삭제·음성만 삭제·계속 보관만 할 수 있다. 재생 시간은 학습 시간에 포함하지 않는다. 목록에는 실제 녹음(`RECORDING`)만 나오고, AI가 만든 예시 음성(`PROMPT`)은 화면에 표시하지 않은 채 보관 기한이 지나면 정리된다.

## 말하기·쉐도잉

영어 학습 **말하기** 탭의 **새 말하기 시작** 또는 듣기 공간의 **짧은 구간 쉐도잉**에서 시작한다. **연습 문장과 AI 음성 만들기**를 누르면 짧은 영어 문장과 한국어 뜻, 다시 들을 수 있는 AI 모범 음성을 저장한다. 기본 난이도는 쉬운 일상 영어이며 주제는 선택 사항이다.

- **마이크 켜고 녹음**을 누를 때만 마이크 권한을 요청한다. 최대 60초·10MiB이며 브라우저 종료 지연을 고려해 59초에 정지를 요청한다. 먼저 녹음을 들어 보거나 내려받고, **이 녹음 분석하기**를 눌러야 서버와 AI로 전송된다.
- 녹음·음성 재생은 기존 단일 세션 타이머에 반영한다. 권한 확인·전송·분석 대기는 제외한다. 일시 정지·종료·화면 숨김·다른 기기 전환 때 재생과 마이크를 멈춘다.
- 미분석 녹음은 사용자·공간별 IndexedDB에 약 1초마다 보관하고 정지 시 마무리한다. 새로고침 후 복원할 수 있지만 브라우저 강제 종료 직전의 마지막 조각은 손실될 수 있다. 로그아웃하면 기기에 남은 녹음을 지운다. 브라우저 저장소가 차단됐으면 내려받기 안내를 표시한다.
- 원래 인식 문장과 사용자가 수정한 문장을 별도로 보존한다. 기준 문장이 있으면 처음 300단어 안에서 누락·추가 후보를 최대 40개 표시한다. 발음 점수나 억양 평가가 아니며, 기준 문장이 없으면 자유 발화의 표현·문법 피드백을 제공한다.
- YouTube의 **짧은 구간 쉐도잉**에서 5–30초 구간을 듣고 자동으로 멈춘 뒤 녹음한다. 기준 문장은 직접 입력하거나 선택 자막을 붙여 넣는다. 마이크를 켜기 전에 영상을 멈춘다.
- 서버 음성은 비공개 Storage에 기본 30일 보관한다. **계속 보관**을 선택할 수 있고, **음성만 삭제 · 인식문 유지**와 **음성과 기록 삭제**를 구분한다. 삭제 요청 즉시 접근을 막고 Worker가 파일 삭제를 재시도한다. AI를 꺼도 Supabase 연결이 설정된 Worker는 보관 기간·계정 삭제 정리를 계속 수행한다.
- 음성 요청은 하루 30회·분당 10회, 영어 학습 글쓰기와 음성 합계 동시 3개로 제한한다. 반복 재생은 새 AI 요청을 만들지 않는다. 이 동시 제한에 기존 도서 AI 작업은 포함하지 않는다.

Worker의 기존 OpenAI 키를 사용한다. 기본 모델은 `OPENAI_TRANSCRIBE_MODEL=gpt-4o-mini-transcribe`, `OPENAI_TTS_MODEL=gpt-4o-mini-tts`, `OPENAI_TTS_VOICE=marin`이며 문장과 피드백은 기존 `OPENAI_MODEL`로 생성한다. 모델 사용 방식은 [OpenAI 음성 생성](https://platform.openai.com/docs/guides/text-to-speech), [음성 인식](https://platform.openai.com/docs/guides/speech-to-text) 문서를 따른다. 실제 형식·크기·길이·무음 검사는 Worker의 제한된 ffmpeg 프로세스에서 수행한다.

## YouTube로 공부하기

`/learn/listening`의 영상 링크 입력에 한 줄씩 최대 20개를 붙여 넣는다. 같은 영상은 기존 자료를 재사용하고 잘못된 링크는 항목별로 안내한다. Google 계정 연결은 필요 없다. 저장한 영상을 선택하면 `/learn/items/{id}`에서 공식 플레이어가 열린다.

듣기 방은 **영상·메모 / 말하기 / 질문·노트 / 자료** 탭으로 나뉘어 한 번에 한 가지만 보여준다. 현재 탭은 주소의 `?view=`에 남아 새로고침과 뒤로가기에서 유지되며, 알 수 없는 값이나 그 방에 없는 탭은 기본 탭으로 정리한다. 영상 탭을 벗어나면 영상을 멈추고 마지막 위치를 저장하고, 녹음 중에 탭을 옮기려 하면 한 번 확인한다. 말하기·쓰기 방은 활동이 하나여서 탭을 표시하지 않는다.

- 마지막 저장 위치에서 재생하고, 지원 배속과 A–B 반복을 사용할 수 있다. 영상의 재생 위치와 실제 경과한 학습 시간은 별도로 기록한다. 탐색으로 건너뛴 구간은 시청 구간으로 인정하지 않는다.
- 일시 정지·종료·화면 숨김 때 영상을 멈추고 마지막 위치를 동기화한다. 일시 정지 뒤 화면이 보이는 상태에서 다시 재생하면 학습 시간도 함께 재개한다. 플레이어가 정지·버퍼링 중이면 시청 활동은 멈춘다. 동시에 글을 쓰는 경우에는 같은 세션의 글쓰기 시간이 이어질 수 있다.
- 아직 이름을 붙이지 않은 영상은 목록에서 YouTube 공개 oEmbed로 실제 제목을 받아 보여준다. 받은 제목은 화면에만 쓰고 DB·브라우저 저장소·AI 입력 어디에도 저장하지 않는다. 요청이 실패하면 저장된 이름(`YouTube · 영상ID`)을 그대로 보여준다. **영상 제목과 보관 설정**에서 직접 붙인 제목은 덮지 않는다.
- 목록의 **목록에서 지우기**는 저장한 영상만 지운다. 확인을 한 번 거치며, 그 영상으로 공부한 시간과 메모는 남으므로 통계와 학습 잔디의 과거 숫자가 바뀌지 않는다. 같은 링크를 다시 저장하면 새 학습으로 만들어진다.
- **메모**에서 현재 영상 시각과 함께 글을 저장한다. 저장한 시각을 누르면 그 위치로 이동한다.
- **PaceOn에서 본 구간**은 영상·메모 탭에 둔다. 플레이어가 보이지 않는 탭에서는 YouTube가 이동 명령을 처리하지 않으므로, 구간을 누르면 바로 그 위치로 이동하도록 목록을 플레이어와 같은 탭에 둔다. 같은 날·같은 배속으로 2초 이내에 이어진 구간은 한 줄로 묶고 "N회 이어 봄"으로 횟수를 남긴다. 최근 날짜가 먼저 오고 같은 날 안에서는 영상 위치 순으로 정렬한다.
- **자막 · AI 원문**에서 TXT/SRT/VTT 파일(1MiB 이하)이나 텍스트를 넣고, AI에 사용할 부분을 선택해 저장한다. 저장 원문은 100,000자, 선택 부분은 12,000자 이하다. 자동 자막 수집은 하지 않는다.
- AI 질문과 정리는 선택한 자막, 최근 메모 20개, 저장된 대화를 근거로 한다. 요청 전체는 20,000자 이하여야 한다. 자막이 없으면 메모와 대화만 참고하며, 영상 전체를 시청한 것처럼 요약하지 않는다.
- API에서 불러온 Google 목록 제목은 화면에서만 사용한다. 선택 저장은 영상 URL만 전달하므로 연결 해제 뒤 개인 학습 기록에 외부 계정 정보가 섞이지 않는다.

**YouTube 계정 연결**은 재생목록·구독 채널의 영상 선택을 위한 별도 기능이다. 서버 코드와 제공자 fixture 검증은 완료했지만 Google 프로젝트가 없어 실제 계정 동의는 아직 검증하지 않았다. [Google 프로젝트 및 OAuth 설정 안내](YOUTUBE_SETUP.md)에 따라 준비한다. 계정 연결로 광고 제거·Premium 인증·YouTube 전체 시청 기록 동기화를 제공하지 않는다. 연결 관리는 **설정**(헤더 톱니 아이콘)에서 하고, 듣기 탭에서는 **YouTube에서 가져오기**로 영상을 고른다.

## 사용 방법

1. 로그인 후 `/learn` 또는 메뉴의 **영어 학습**을 연다. 마지막으로 본 영역 탭으로 이동한다(기본은 듣기).
2. **듣기**에서는 영상 링크를 저장하거나 **YouTube에서 가져오기**로 영상을 고른다. **말하기**에서는 **새 말하기 시작**, **쓰기**에서는 **새 글 쓰기**를 누른다. 글을 쓰면 학습 시간이 시작된다.
3. 초안은 기기에 즉시, 서버에 약 3초 뒤 저장한다. 다른 기기의 수정과 충돌하면 두 초안을 확인하고 선택한다.
4. **AI에게 보내기**로 원문을 저장하고 첨삭·표현·예문·다음 연습을 받는다.
5. **일시 정지 / 학습 재개 / 학습 종료**로 시간을 관리한다. **이번 학습 정리하기**는 해당 세션에서 AI에 보낸 대화를 요약한다. 보내지 않은 초안은 포함하지 않는다.

종료한 공간에서도 초안과 노트를 계속 볼 수 있다. 다시 쓰면 새 세션을 시작한다. 다른 탭이나 기기에서 진행 중이면 **이 기기로 학습 옮기기**를 눌러야 계측 소유권이 바뀐다. 화면 숨김·1분 무활동은 자동 정지한다. 직접 정지한 세션은 **학습 재개**를 누르거나 영상을 다시 재생하면 재개한다. 메모·글 입력만으로는 재개하지 않으며, 말하기 녹음도 자동으로 다시 시작하지 않는다.

## 실행 및 검사

기존 Supabase Local과 Next.js를 사용한다. LR1·LR2와 LR3의 `20260924000000`부터 `20260930000000`까지, 영역 분리의 `20261001000000` 마이그레이션을 `supabase migration up --local`로 적용하고 `pnpm db:types`로 타입을 생성한다. 데이터 초기화는 필요 없다.

웹 `AI_ENABLED=true`, Worker의 기존 `AI_ENABLED`, `OPENAI_API_KEY`, `OPENAI_MODEL` 설정을 사용한다. 키는 Worker에만 두며 새 브라우저 키는 필요 없다. Worker 재빌드:

```powershell
docker compose --env-file services/ai-worker/.env -f docker/docker-compose.yml up -d --build ai-worker
```

검사 명령:

```powershell
pnpm test
pnpm lint
pnpm typecheck
pnpm build
pnpm db:test
pnpm db:types:check
pnpm test:learning:integration
pnpm test:speech:integration
```

통합 검사는 빌드된 웹앱을 임시 포트에서 실행하고 테스트 계정을 생성·삭제한다. 큐 접수까지 검증하므로 실제 Worker가 실행 중이면 테스트 문장이 AI에 전달될 수 있다. 비용 없는 반복 실행에는 별도 로컬 테스트 환경에서 Worker를 정지한다. 완료 출력·소유권·재시도는 pgTAP와 Worker 단위 테스트로 별도 검증한다.

## 현재 범위와 제한

- AI는 저장된 작업을 처리하고 화면이 결과를 주기적으로 확인한다. 토큰 스트리밍·생성 취소는 아직 없다.
- 메시지는 8,000자, 요청 문맥은 20,000자다. 긴 대화는 자동으로 잘라 분석하지 않고 한도 오류로 안내한다. 새 공간에서 이어서 작성할 수 있다.
- 자동 AI 전송은 하지 않는다. 요약도 버튼을 눌러 요청한다. AI를 끄거나 제공자 장애가 나도 초안과 세션 기록을 보관한다.
- 학습 시간은 서버 시간으로 확정한다. 네트워크 단절·브라우저 종료 뒤의 미확인 시간을 임의로 추가하지 않는다. 세션의 시간대와 UTC 활동 구간을 보존한다.
- 현재 열린 화면에서 초안을 기기에 보관하지만, 오프라인에서 앱을 새로 여는 기능은 보장하지 않는다. PWA는 LR5다.
- 표현 복습·기존 통계 통합은 다음 LR4다. 영어 학습 기록을 기존 도서 페이지 진도에 합산하지 않는다.
- 공간 이름 변경·보관·삭제 UI, 운영 비용 경보, 스트리밍과 부분 응답 복원은 후속 작업이다.
