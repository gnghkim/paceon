# 완료 기록

책을 다 읽거나 교재·강의를 모두 마치면 그동안의 기록을 한 장의 카드로 보여 준다. 책은 **완독 기록**, 교재·강의는 **완료 기록**이라고 부른다.

## 보여 주는 것

| 항목 | 계산 |
| --- | --- |
| 시작일 | 첫 읽기(학습) 기록의 학습일 |
| 완료일 | 마지막 읽기(학습) 기록의 학습일 |
| 기간 | 완료일 − 시작일 + 1일. 시작일과 완료일을 모두 센다 |
| 실제 읽은(공부한) 날 | 기록이 있는 날짜 수. 하루에 여러 번 남겨도 하루다. "28일 중"을 함께 보여 준다 |
| 하루 평균 | 기록으로 해낸 분량 ÷ 실제 읽은 날. 소수 첫째 자리까지. 책은 쪽, 교재·강의는 마친 챕터 수(자료의 단위 이름: 강, 과 …) |
| 기록한 시간 | 기록에 적은 분의 합. 시간을 비운 기록이 있으면 "시간을 비운 기록 N번 제외"를 붙인다. 0분이라고 적은 것은 비운 것이 아니다. 모두 비웠으면 "적지 않음" |
| 목표 대비 | 마친 계획에 목표일이 있을 때만. "목표보다 3일 일찍", "목표일에 맞춰 끝냈어요", "목표보다 2일 늦게". 일찍이거나 맞췄으면 초록색이고, 늦은 것은 탓하지 않게 보통 글자색이다 |

- 무효 처리한 기록과 복습(다시 공부한 것)은 세지 않는다. 처음 해낸 분량만 센다.
- 등록할 때 이미 읽은 쪽은 하루 평균에 넣지 않고 "등록할 때 이미 20쪽까지 읽어 둔 상태였어요"로 따로 알린다.
- 완료는 자료의 상태(`resources.status = 'COMPLETED'`)로 판단한다. 보관한 자료에는 카드가 없다.
- 기록 없이 다 읽은 상태로 등록한 책은 날짜를 말할 근거가 없어 카드를 만들지 않는다.

따로 저장하지 않는다. 화면이 이미 불러온 기록과 계획에서 매번 계산하므로 기록을 고치거나 완료를 취소하면 카드도 따라 바뀌거나 사라진다. DB와 API 변경은 없다.

## 보이는 곳

| 위치 | 언제 |
| --- | --- |
| 도서 상세, 교재·강의 상세 | 다 마친 동안 늘. 제목 바로 아래 |
| 완료 순간의 창 | 마지막 기록을 저장한 그때. 떠올리기(회상)를 마치거나 건너뛴 뒤에 뜬다 |

완료 순간의 창은 독서 기록 창, 도서 상세의 학습 기록, 교재·강의의 학습 기록 창 어디서 저장해도 뜬다. 책은 "다 읽었어요", 교재·강의는 "모두 마쳤어요"가 제목이다. 다른 화면에서 마쳤으면 **상세에서 보기**로 그 자료의 상세로 간다. 이미 다 읽은 책의 마지막 기록을 고친 것처럼 저장 전에도 끝나 있던 경우에는 다시 띄우지 않는다.

## 구현

| 위치 | 역할 |
| --- | --- |
| `apps/web/src/lib/completion-record.ts` | `completionRecord`(계산), `describeTarget`, `formatStudyMinutes`, `justCompleted`(이번 저장으로 처음 끝났는지) |
| `apps/web/src/components/completion-record.tsx` | `CompletionCard`, 상세 화면의 `CompletionRecordCard`, 완료 순간의 창을 여는 `CompletionProvider`와 `useCompletionMoment` |

`CompletionProvider`는 앱 셸에서 기록 창들보다 바깥에 있다. 책은 `ProgressForm`이 저장 전후의 진도로 `justCompleted`를 보고, 교재·강의는 학습 기록 창이 서버가 돌려준 `done`과 `total`이 같아졌는지 보고 창을 연다. 창은 열릴 때 서재를 새로 읽어 방금 기록까지 넣어 계산한다.

## 검증 (2026-10-09)

- `pnpm test`: 시작일·완료일·기간·실제 읽은 날(같은 날 두 번은 하루), 무효 기록·복습·다른 자료 제외, 등록 때 읽은 쪽 제외, 하루 평균 소수 한 자리, 끝나지 않은 자료·보관한 자료·기록 없는 자료는 카드 없음, 챕터형 자료는 작업량이 아니라 챕터 수, 0분과 비운 시간 구분, 목표 대비(일찍·맞춤·늦게·없음, 가장 최근의 마친 계획), 시간 표기, 완료 순간 판정(이미 끝난 책 정정은 아님).
- 실제 브라우저(390×844, 1280×800). 등록 때 20쪽, 280쪽까지 6번 기록한 책과 3강 중 2강을 마친 강의로 확인했다.
  - 끝나기 전에는 카드가 없다.
  - 독서 기록 창에서 300쪽을 저장하고 떠올리기를 건너뛰면 "다 읽었어요" 창이 뜬다. 숫자는 9월 12일부터 10월 9일까지 28일, 6일, 하루 평균 46.7쪽, 3시간 30분(비운 기록 2번 제외), 목표보다 3일 일찍이었다.
  - 그 책의 상세에서 마쳤을 때는 상세로 가는 단추가 없고, 닫으면 상세에 같은 카드가 보인다.
  - 강의의 마지막 강을 저장하면 "모두 마쳤어요"가 뜨고 상세에 완료 기록이 생긴다. 완료를 취소하면 카드가 사라진다.
  - 가로 넘침과 페이지 오류는 없었다. 확인에 쓴 계정은 지웠다.
