# Phase 7 PDF Import Implementation Plan

> Use superpowers:subagent-driven-development for independent tasks. Existing product scope and user continuation authorize implementation. Leave this phase uncommitted.

**Goal:** Upload a private PDF, durably extract pages/text/bookmarks without an AI key, review it, and register a page-based learning resource with units and the existing planning/progress/AI flow.

**Architecture:** Supabase private Storage `learning-pdfs`, authenticated Next proxy for bounded raw uploads/downloads, durable `pdf_imports` queue, separate Python consumer using isolated pypdf subprocess, transactional confirmation creates BOOK/PAGE resource and units. PDFs are represented as BOOK with source `PDF_IMPORT` for compatibility with the existing page scheduler; UI labels their PDF origin. No OCR, password entry, remote PDF fetch, or AI-created page counts.

## Exact shared contract

Maximum10MiB=10485760 bytes, PDF header `%PDF-` at byte0, maximum500 pages. Filename sanitized string<=200. Bucket private allowedmime application/pdf file_size_limit10485760. Path `USER_UUID/IMPORT_UUID.pdf`, generated by server/RPC; never accepts user-chosen URL/path. INSERT/SELECT Storage RLS own prefix, immutable objects(no update/upsert), DELETE owner permitted for cleanup. Storage service role remains Worker-only. No public URLs.

`pdf_imports`: id uuid client-generated retry key, user_id uuid auth cascade, filename text, storage_path text unique, file_size integer, content_sha256 hex64; status UPLOADING/PENDING/PROCESSING/READY/FAILED/IMPORTED; result jsonb nullable; error_code text nullable; attempts integer0..3; lease_token uuid nullable; lease_expires_at timestamptz nullable; resource_id uuid nullable references resources(id,user_id); created_at/updated_at timestamps. Owner SELECT only, mutations through named RPCs. Per-user active cap5 (UPLOADING/PENDING/PROCESSING), PT429. One file perimport ID; repeated ID must match filename,size,hash.

RPCs:
- `begin_pdf_import(p_id uuid,p_filename text,p_file_size integer,p_content_sha256 text) returns jsonb`: authenticated, verifiesowner/retry fields, inserts UPLOADING or returns identical owned row; foreignID42501, mismatched retry40001.
- `queue_pdf_import(p_id uuid) returns jsonb`: authenticated, own storage object exists(path/bucket/size), UPLOADING→PENDING, already queued/finished idempotentlyreturnsrow. Never accepts result/status from client.
- `retry_pdf_import(p_id uuid) returns jsonb`: authenticated FAILED→PENDING attempts0, confirmsobjectstillpresent, activecap5; only parsing retry, never mutates importedresource. UPLOADING upload retry uses original ID+samefile in POST.
- `discard_pdf_import(p_id uuid) returns boolean`: authenticated deletes owned non-IMPORTED/non-PROCESSING row (for cancel/cleanup), returnsfalse missing,409 forbiddenstate. API first RPCdiscard then deletes same owned object; if Storage deletion fails usergets503 but importrowgone (document cleanup limitation). No recursive/global cleanup.
- `claim_pdf_import() returns jsonb`: serviceonly skiplocked claimsPENDING/expiredPROCESSING with120secondlease/max3attempts, exhaustionFAILED WORKER_TIMEOUT.
- `finish_pdf_import(p_id uuid,p_lease_token uuid,p_result jsonb,p_error_code text) returns boolean`: serviceonly matchinglivelease; strict validates parsedresult and atomic READY orFAILED; safeuppercasecodeonly.
- `confirm_pdf_import(p_id uuid,p_title text,p_current_page integer) returns uuid`: auth ownREADY, validates1..500 actual pageCount, initialcurrent0..total. Idempotent IMPORTED returns existingresource only if same title/currentPage; differentpayload409. Creates BOOK/PAGE sourcePDF_IMPORT source_id importuuid, statusCOMPLETED iffcurrent==total, total_units unitcount. Creates top-level SECTION units sequence1..N title/start/end/workload; verifiescontiguous nonoverlap fullcoverage1..pageCount. Setsimport IMPORTED +resource_id transactionally. Existing initialplan/progress APIs work unchanged.

Parser result strict JSON:
`{pageCount:integer1..500,title:string1..500,units:[{title:string1..500,startPage:integer,endPage:integer}]1..500,textExcerpt:string<=12000,analysisOutline:string<=12000,warnings:('NO_TEXT'|'NO_OUTLINE'|'TRUNCATED_TEXT'|'INVALID_OUTLINE')[]}`.
Use deterministic top-level PDF bookmarks if valid (sort unique ascending page), fill frontmatter1..firstbookmark-1, infer ends nextstart-1. Fallback one Whole document unit on absent/invalid bookmarks. No guessed semantic headings. No-text scanned PDFs remain READY with NO_TEXT warning and valid pagecount; no OCR claimed. Encrypted (even empty password), malformed, oversize, excessivepages fail with distinctsafe codes.
