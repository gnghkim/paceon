# 메뉴 UI/UX 개선 검증 기록

날짜: 2026-09-19

## 반영 내용

- PC·모바일 주 메뉴를 오늘 / 영어 학습 / 캘린더 / 서재 / 통계로 통일하고, 독서 기록을 별도 행동 버튼으로 분리했다.
- 영어 학습의 듣기·말하기·쓰기 탭을 제목 다음에 배치했다. 이어하기는 해당 영역만 표시하며 PC는 최대 3개, 모바일은 기본 1개와 더 보기를 제공한다.
- 서재의 전체 / 책 / 교재·강의 필터와 공통 제목·저자 검색, 자료 추가 진입 화면을 적용했다.
- 공통 복습을 `/review`로 옮기고 오늘 메뉴에 소속시켰다. 기존 `/learn/review`는 새 경로로 연결한다.
- 캘린더에서 교재·강의의 제목·단위·상세 경로를 올바르게 표시한다.
- 자료가 없는 계정도 학습 가능 시간을 처음 저장하고 교재 계획으로 돌아갈 수 있다.
- 설정·계정 표시, 메뉴 용어, 터치 영역과 하단 안전 영역 여백을 정돈했다.

## 자동 검증

- `pnpm typecheck`: 통과.
- `pnpm lint`: 통과.
- `pnpm test`: Node 테스트 400개와 스케줄러 테스트 52개 통과.
- `pnpm build`: 통과. `/resources/add`, `/review`, `/settings`를 포함한 프로덕션 라우트 생성 성공.

추가 검증은 자료별 일정 표시와 경로, 첫 시간 설정 입력·복귀 경로, 메뉴 소속, 서재 필터, 영역별 이어하기, 복습 상태를 대상으로 한다. 기존 API·복습 계산·스케줄러 테스트도 함께 실행했다.

## 실제 브라우저 확인

로컬 Supabase와 임시 계정으로 확인했으며, 검증 종료 후 임시 계정을 삭제했다.

| 환경·시나리오 | 결과 |
| --- | --- |
| 책이 없는 신규 계정 | 빈 시간 입력에서 저장이 비활성화됨. 토·일 각 60분 저장 후 원래 교재로 복귀하고 계획 생성 성공. API 재조회에서 책 0개, 교재 1개, 시간 2개, 계획 1개, 일정 2개 확인 |
| PC 캘린더 | 강의 제목·단원·시간이 표시되고 작은 일정 링크에서 해당 교재 상세로 이동 |
| 320×740 영어 쓰기 | 가로 넘침 없음. 영역 탭이 첫 화면에 표시됨. 쓰기 자료만 기본 1개, 더 보기 후 4개 표시 |
| 320×740 서재 | 교재·강의 필터에서 저자 검색 성공. 책 상태 필터가 노출되지 않고 가로 넘침 없음 |
| 기록 대화상자 | 헤더에서 열기, Escape로 닫기, 독서 기록 버튼으로 초점 복귀 확인 |
| 복습 이전 URL | `/learn/review`에서 `/review`로 이동 확인 |
| 복습 삭제 실패 후 재시도 | 요청을 차단해 오류를 확인한 후 재시도 성공. 마지막 항목 삭제 후 빈 상태가 표시되고 이전 오류·저장 개수가 남지 않음 |
| 390×844 자료 추가, 라이트 | 책 검색·직접 입력, PDF, 교재·강의 진입점과 서재 활성 표시 확인 |
| 768×1024 자료 추가, 다크 | PC 사이드바 전환, 서재 활성 표시, 가로 넘침 없음 확인 |

로컬 화면 증거는 작업 폴더의 `.artifacts/menu-ux/`에 보관했다. 실제 휴대전화의 소프트 키보드·노치·터치 조작은 검증하지 않았다. 기존 외부 책 검색·PDF 처리·YouTube 연동 전체를 브라우저에서 다시 실행하지는 않았으며, 관련 기존 경로와 자동 테스트를 유지했다. 설계 문서의 세부 수용 체크리스트는 추가 수동 회귀 확인에 사용할 수 있도록 남겼다.

DB 마이그레이션과 운영 배포는 포함하지 않는다.
