# 설정 버전 정보 표시 설계

작성일: 2026-09-19

## 목표

설정 화면에서 현재 배포본이 어떤 Git 커밋으로 만들어졌는지 사용자가 확인할 수 있게 한다. 버전은 최신 커밋의 작성 날짜와 7자리 축약 해시를 결합한 `YYYYMMDD-abcdef0` 형식으로 표시한다. 현재 기준 예시는 `20260919-c77112d`다.

## 버전 생성

Next.js 설정을 평가하는 빌드 시점에 Git에서 다음 값을 읽는다.

- 날짜: `git log -1 --format=%cs` 결과에서 하이픈을 제거한다.
- 해시: `git rev-parse --short=7 HEAD` 결과를 사용한다.

두 값을 결합해 `NEXT_PUBLIC_APP_VERSION` 환경 변수로 클라이언트 번들에 주입한다. 요청마다 Git을 실행하지 않으며 별도의 버전 파일을 수동으로 관리하지 않는다.

Git 메타데이터가 없는 배포 환경에서는 공급자가 제공하는 커밋 해시 환경 변수를 사용한다. 날짜를 함께 확인할 수 없으면 잘못된 날짜를 만들지 않고 `개발 버전`을 표시한다. 명시적인 `NEXT_PUBLIC_APP_VERSION` 값이 있으면 이를 가장 우선한다.

## 화면 표시

설정 화면의 계정 섹션 아래에 `버전 정보` 섹션을 추가한다. 카드 안에 `앱 버전` 레이블과 생성된 문자열을 표시한다. 버전은 식별값이므로 고정폭 글꼴을 사용하고, 복사 기능이나 업데이트 확인 기능은 이번 범위에 포함하지 않는다.

## 검증

버전 문자열을 만드는 로직을 작은 함수로 분리하고 다음 동작을 테스트한다.

- 커밋 날짜와 해시가 있으면 `YYYYMMDD-7자리해시`를 반환한다.
- 날짜의 하이픈과 해시 앞뒤 공백을 제거한다.
- 명시적 앱 버전이 있으면 Git 계산 결과보다 우선한다.
- 필수 Git 정보가 없으면 `개발 버전`을 반환한다.

설정 화면에 `버전 정보`와 생성된 앱 버전이 포함되는지 확인하고, 타입 검사·린트·전체 테스트·프로덕션 빌드를 실행한다.
