# PaceOn 영어학습 확장 기능 명세서

작성일: 2026-09-14
상태: 전체 확장 명세 · LR1·LR2 구현 (실제 Google 계정 연결은 프로젝트 설정 후 확인)
대상: 모바일 우선 웹앱, 초기 학습 언어 영어 / 안내 언어 한국어

## 1. 목적과 범위

PaceOn 안에서 자료를 고르고 실제로 공부하며, 활동과 배운 내용을 기록하고 다음 복습까지 이어간다. 사용자는 짧은 자투리 시간에도 계획 설정이나 복잡한 입력 없이 학습을 시작할 수 있어야 한다.

기본 흐름은 **앱 열기 → 이어하기 또는 자료 선택 → 공부**다. 목표, 수준, 학습 시간, 태그 입력을 시작의 필수 조건으로 두지 않는다. 학습 종료나 AI 요약 완료도 기록 저장의 필수 조건이 아니다.

### 1.1 논의한 요구사항

| ID | 요구사항 | 범위 |

### 1.2 이번 문서에서 제외하는 범위

- 네이티브 iOS/Android 앱, 백그라운드 재생·녹음 보장.
- 유튜브 영상/오디오 파일 다운로드, 광고 제거, 임의의 공개 영상 자막 자동 수집.
- OAuth 연결만으로 Premium 혜택 활성화·가입 여부 판정, YouTube 전체 시청 기록·‘나중에 볼 동영상’ 자동 동기화.
- 외부 ChatGPT 계정의 대화 자동 동기화, 유료 ChatGPT 구독과 API 사용량 연동.
- 실시간 음성 통화형 AI 튜터, 검증된 발음 점수·공인 언어 수준 판정.
- 소셜 피드, 친구 경쟁, 강제 연속 학습, 모든 과목에 대한 자동 교육과정 생성.

## 2. 현재 시스템과 연결

현재 구현된 기능은 도서·PDF 등록, 페이지 기반 학습 계획, 진도·복습 기록, 도서 AI 분석/코칭, 기간별 통계, 간편 기록창이다. 영어학습은 **새 확장 기능**이며 이 문서 자체가 구현 완료를 의미하지 않는다.

| 현재 기능 | 확장 원칙 |
| --- | --- |
| 도서 `resources`, `plans`, `schedule_sessions` | 기존 페이지 계획을 유지한다. 영어학습 시작에 도서 계획을 요구하지 않는다. |
| `progress_events` | 도서 진도 전용 계약을 유지한다. 시청·대화·녹음을 페이지로 환산하지 않는다. |
| 간편 기록창 | 기존 도서 기록 접근 유지. 향후 영어학습 활동의 수동 기록 진입점을 함께 제공한다. |
| AI Worker / `ai_jobs` | 서버 전용 키, 큐, 검증, 재시도 원칙을 재사용한다. 기존 도서 전용 작업 계약에 영어학습 ID를 억지로 넣지 않는다. |
| 학습 통계 | 도서 분량과 영어학습 활동량을 구분한다. 시간과 활동일은 출처가 드러나는 통합 지표를 제공한다. |

관련 문서: [아키텍처](ARCHITECTURE.md), [AI](AI.md), [간편 기록](QUICK_RECORD.md), [통계](STATISTICS.md).

## 3. 화면과 진입 흐름

### 3.1 영어학습 홈 `/learn`

상단부터 다음 순서로 배치한다.

1. **이어서 공부하기**: 최근 학습 3개. 영상 위치, 마지막 대화, 연습 문장과 짧은 안내를 표시한다.
2. **바로 연습하기**: 문장 하나 따라 읽기 / 한 문장 쓰기 / 오늘의 복습.
3. **저장한 영상**: 썸네일, 제목, 마지막 위치, 즐겨찾기. 탭하면 해당 영상 학습 공간을 연다.
4. **최근 학습 노트**: 저장된 원문·대화·AI 정리로 이동한다.

비어 있을 때에는 ‘영상 링크 붙여넣기’와 ‘한 문장 쓰기’를 먼저 제시한다. 영상 목록이나 AI 추천을 불러오는 동안에도 텍스트 작성은 가능해야 한다.

### 3.2 모바일 메뉴

- 하단: **오늘 / 영어학습 / 독서 / 라이브러리 / 통계**의 5개 항목을 제안한다.
- 기존 캘린더는 오늘 화면 상단의 명시적 ‘캘린더’ 링크로 접근한다. 기존 `/calendar` 주소는 유지한다.
- 가운데 ‘독서’는 도서 진도 기록을 유지한다. 영어학습은 옆의 전용 항목에서 한 번에 연다.
- PC 사이드 메뉴에는 오늘·영어학습·캘린더·라이브러리·통계를 표시한다.
- 휴대폰 화면과 키보드가 겹치지 않도록 작성·전송·녹음 종료 버튼을 보이는 영역에 둔다.

메뉴 변경은 본 명세의 제안이며, 도서 기록 사용성을 회귀 검증한 뒤 적용한다.

### 3.3 빠른 시작과 이어하기

- 기존 자료는 홈에서 선택 후 본문을 바로 보여준다. 브라우저 정책상 재생 버튼을 한 번 더 눌러야 할 수 있다.
- 처음 한 번만 수준·관심 주제 설정을 선택적으로 제공한다. 건너뛰면 쉬운 일상 영어와 한국어 설명을 기본값으로 사용한다.
- ‘3분’은 콘텐츠 추천 길이이며 자동 종료 제한이 아니다. 계속하기를 허용한다.
- ‘말하기 어려워요’ 선택 시 녹음·소리 재생 없이 가능한 글쓰기·텍스트 복습을 먼저 제시한다.
- 이어하기는 마지막으로 사용한 **학습 공간**을 연다. 이전에 종료된 시간 기록을 다시 늘리지 않고 새 활동 세션을 시작한다.
- 학습 기록 목록에서 ‘같은 자료로 다시 공부’와 ‘이전 기록 보기’를 구분한다.

### 3.4 학습 타이머와 제어 버튼

- 모든 학습 공간에 **이번 학습 05:32 · 학습 중**과 **일시 정지 / 학습 종료** 버튼을 표시한다. 1시간 이상이면 `01:05:32` 형식으로 표시한다.
- 모바일은 상단에 작은 타이머를 유지하고 주요 제어를 키보드·영상 컨트롤과 겹치지 않는 위치에 둔다. 타이머를 보기 위해 다른 탭으로 이동할 필요가 없어야 한다.
- 타이머 값은 7.3절의 인정 활동 시간이며 세션을 연 뒤의 단순 경과 시간이 아니다. 서버가 승인한 누적 시간에 아직 전송하지 않은 유효 구간을 더해 1초 단위로 표시한다.
- 서버 미확인 구간은 ‘동기화 중’, 무활동·화면 숨김·연결 단절로 계측이 멈추면 ‘자동 일시 정지’로 표시한다. 확정 기록과 차이가 발생하면 서버 결과로 보정한다.
- **일시 정지**: 계측 구간을 닫고 초안·영상 위치를 저장한다. 영상·모범 음성을 일시 정지하고 진행 중 녹음을 종료해 미분석 초안으로 보존한다. 기존 AI 작업은 계속될 수 있으나 대기 시간은 집계하지 않는다.
- 일시 정지 중에는 버튼을 **학습 재개**로 바꾼다. 사용자가 누르기 전에는 입력이나 플레이어 이벤트만으로 명시적 일시 정지를 해제하지 않는다. 재개해도 마이크는 자동으로 켜지지 않는다.
- **학습 종료**: 진행 중 활동과 녹음을 멈추고 마지막 구간·초안을 저장한 뒤 세션을 종료한다. ‘이번 학습 5분 32초’와 기록된 활동을 보여준다. AI 정리는 설정에 따라 비동기로 수행한다.
- 종료 시 녹음은 저장하되 분석 동의를 대신하지 않는다. 자동 정리를 끈 사용자는 결과 화면에서 ‘정리하기’를 선택할 수 있다.
- 종료 저장이 실패하면 ‘종료 동기화 대기’로 표시하고 로컬 종료 이벤트를 재전송한다. 종료 버튼을 다시 눌러도 세션이나 시간이 중복 생성되지 않는다.
- 종료한 공간은 다시 열 수 있지만 다음 활동은 새 세션으로 계산한다. 타이머와 종료 버튼은 편의를 위한 것으로, 종료 버튼을 누르지 않았다는 이유로 기존 기록을 버리지 않는다.

## 4. 유튜브 리스닝

### 4.1 링크 저장

- 한 링크 붙여넣기와 여러 줄 붙여넣기를 지원한다. 1회 최대 20개를 저장한다.
- 지원 URL: `youtube.com/watch?v=`, `youtu.be/`, `youtube.com/shorts/`, `youtube.com/embed/`의 단일 영상. 재생목록 URL 일괄 확장은 초기 범위에서 제외하며, 연결 계정의 재생목록에서 항목을 선택하는 기능은 4.4절을 따른다.
- URL에서 영상 ID와 시작 시각을 정규화한다. 허용된 HTTPS 호스트만 처리하며 사용자 URL을 서버가 임의로 요청하지 않는다.
- 사용자별 같은 영상 ID는 한 자료로 관리한다. 중복 등록 시 기존 자료를 안내하고 재사용한다.
- 여러 링크 중 일부가 실패해도 성공 항목은 남기고 항목별 재시도를 제공한다.
- 제목·썸네일 조회 실패가 학습 자료 저장을 막지 않는다. 임시 제목과 직접 수정 기능을 제공한다.
- 수준, 태그, 목표 시간은 선택 항목이다. 삭제와 보관을 구분한다.

### 4.2 영상 학습 공간 `/learn/items/{id}`

- 공식 임베드 플레이어, 재생/일시 정지, 이전 위치 이어보기, A–B 구간 반복을 제공한다.
- 배속은 플레이어가 해당 영상에서 제공하는 값만 사용한다.
- 모바일에서는 영상 아래 ‘메모 / AI 대화 / 표현 / 쉐도잉’ 탭을 둔다. 화면을 쪼개어 영상과 입력창을 지나치게 작게 만들지 않는다.
- ‘이 구간 메모’는 현재 영상 시각을 기록한다. 저장한 표현을 누르면 원래 구간으로 이동한다.
- 삭제·비공개·임베드 제한 영상에는 이유와 외부에서 열기를 제공한다. 외부에서 본 시간은 자동 기록하지 않는다.
- 영상 종료는 해당 시청 활동을 정지시키되, 이후 메모·대화는 같은 학습 공간에서 계속할 수 있다.

공식 IFrame API는 재생 상태·위치·배속 제어를 제공한다. 플레이어 크기, 기본 컨트롤과 플랫폼 동작을 준수한다. [YouTube IFrame API](https://developers.google.com/youtube/iframe_api_reference)

### 4.3 자막과 AI의 입력 근거

- 1차 구현에서 자막은 사용자가 붙여넣는 텍스트 또는 업로드하는 TXT/SRT/VTT로 받는다. 파일은 최대 1MiB, 정규화한 텍스트는 최대 100,000자로 제한한다.
- 시간 정보가 있는 자막은 구간과 연결한다. 일반 텍스트에 가짜 타임스탬프를 생성하지 않는다.
- 공식 자막 다운로드 API는 권한이 필요한 작업이므로, 공개 영상의 자막을 누구나 API로 받을 수 있다고 가정하지 않는다. [YouTube captions.download](https://developers.google.com/youtube/v3/docs/captions/download)
- 자막이 없으면 영상 시청·구간 반복·시간 기록은 가능하다. AI는 사용자 메모와 대화에 근거해 답변하며 ‘영상 전체를 봤다’고 표현하지 않는다.
- 영상 내용 요약 버튼은 사용할 원문이 있을 때만 활성화한다. 메모만 있으면 ‘내 메모 정리’로 표시한다.
- 자동 자막 확보는 별도의 제공 방식·권한·비용을 검증한 후 추가한다. 비공식 자막 수집을 필수 의존성으로 두지 않는다.

### 4.4 YouTube 계정 연결

목적은 사용자가 기존 계정의 자료를 쉽게 찾아 PaceOn에 저장하는 것이다. PaceOn 로그인과 YouTube 데이터 접근 동의를 분리하고, 계정을 연결하지 않아도 링크 등록과 학습은 가능해야 한다.

- 영어학습의 ‘YouTube 연결’과 설정의 연결 계정 관리에서 Google OAuth를 시작한다.
- 최소 읽기 범위인 `youtube.readonly`를 사용한다. 영상 업로드·구독 변경·재생목록 수정 권한을 요청하지 않는다.
- 초기에는 PaceOn 사용자당 YouTube 계정/채널 한 개를 연결한다. 채널 이름·아이콘·연결 상태를 표시하고 재연결·연결 해제를 제공한다.
- **내 재생목록**: 공식 API로 접근 가능한 사용자의 재생목록과 영상을 페이지 단위로 조회한다. 사용자가 영상을 선택해 1회 최대 20개를 학습 자료에 저장한다. 이미 저장한 영상은 재사용한다.
- **구독 채널**: 구독한 채널을 조회하고 채널의 접근 가능한 공개 영상에서 학습할 항목을 선택한다. 사용자의 개인화된 YouTube 홈 추천과 동일하다고 표현하지 않는다.
- 계정 연결만으로 모든 자료를 자동 수집하지 않는다. 기본 동작은 사용자 조회·선택 시 가져오기이며, 주기적 전체 동기화는 제외한다.
- 취소·권한 철회·토큰 만료·쿼터 초과·채널 없음은 각각 안내한다. 연결 실패가 기존 자료의 학습을 막지 않는다.
- OAuth는 서버에서 처리하고 `state` 검증, 제한된 callback URL, 암호화된 토큰 저장, 만료·철회 처리를 구현한다. 토큰은 UI·로그·AI 입력에 포함하지 않는다.
- 연결 해제 시 자격 증명을 제거하고 가능한 경우 공급자에서 철회한다. API로 가져온 데이터의 보관·갱신·삭제는 YouTube 정책에 맞춰 처리하며, 사용자가 작성한 학습 기록과 구분한다.

공식 지원 근거: [OAuth 인증](https://developers.google.com/youtube/v3/guides/authentication), [재생목록](https://developers.google.com/youtube/v3/guides/implementation/playlists), [구독 채널](https://developers.google.com/youtube/v3/guides/implementation/subscriptions).

### 4.5 Premium과 시청 기록의 지원 경계

- **OAuth 데이터 연결과 임베드 플레이어의 YouTube 로그인 상태는 별개다.** 데이터 API 토큰을 플레이어에 전달해서 Premium을 켜거나 광고를 끄는 기능은 설계하지 않는다.
- Premium 혜택은 YouTube가 해당 재생 환경에서 로그인과 구독 상태를 인식하는지에 달려 있다. PaceOn 연결 완료를 ‘광고 없음’이나 ‘Premium 인증 완료’로 표시하지 않는다.
- 같은 브라우저에서 Premium 계정으로 YouTube에 로그인해도 임베드 환경·쿠키/추적 방지 설정에 따라 실제 적용 여부를 검증해야 한다. 지원 브라우저별 실사용 확인 전 광고 없는 학습을 보장하지 않는다.
- 광고가 보이면 YouTube 로그인 상태를 확인할 수 있는 안내와 ‘YouTube에서 열기’를 제공한다. 외부 시청 시간은 PaceOn이 자동 계측하지 않으며 사용자가 직접 기록할 수 있다.
- 플랫폼 광고를 가리거나 차단하지 않는다. 영상 제작자가 본문에 넣은 협찬·홍보까지 Premium으로 제거된다고 안내하지 않는다. [YouTube Premium 광고 안내](https://support.google.com/youtube/answer/7437519?hl=en)
- **YouTube Data API로 전체 시청 기록과 ‘나중에 볼 동영상’을 가져오는 기능은 제공하지 않는다.** 일반 계정 연결로 이용할 수 없는 기능이다. [playlistItems.list 제한](https://developers.google.com/youtube/v3/docs/playlistItems/list)
- 대신 **PaceOn에서 본 영상** 목록에 영상 제목·마지막 학습일·위치·접한 구간·반복 횟수·인정 시간을 표시한다. 계정 연결 없이도 같은 기록을 제공한다.
- 이 이력은 YouTube 전체 시청 내역이나 YouTube 계정 시청 기록 동기화 결과가 아니다. 외부 YouTube에서 본 영상은 링크 공유/붙여넣기와 수동 학습 기록으로 추가한다.

## 5. AI 라이팅과 학습 대화

### 5.1 시작과 대화

- ‘한 문장 쓰기’는 간단한 주제를 제시한다. ‘자유롭게 쓰기’로 주제 없이 바로 작성할 수 있다.
- 사용자는 GPT API를 사용하는 앱 내부 대화에서 질문, 문장 작성, 수정, 재작성을 한다.
- 유튜브 학습 공간의 AI 대화는 사용자가 지정한 자막 구간·메모를 문맥으로 사용한다.
- 작성 중인 글과 전송한 메시지를 구분한다. 전송 즉시 사용자 메시지를 영속 저장한 뒤 AI 응답을 요청한다.
- 같은 대화의 AI 생성은 한 번에 하나만 진행한다. 중복 전송은 동일 `client_message_id`로 처리한다.
- AI 응답 상태는 대기 / 생성 중 / 완료 / 중단 / 실패로 표시한다. 부분 응답은 완료 응답처럼 표시하지 않는다.
- ‘응답 중지’는 생성 중단을 요청한다. 다시 시도는 기존 사용자 메시지에 대한 새 시도로 기록하고 대화를 중복 추가하지 않는다.

### 5.2 첨삭 형식

1. 내가 쓴 원문.
2. 의미를 유지한 최소 수정안.
3. 핵심 수정 이유 최대 3개.
4. 자연스러운 대안 표현 최대 2개.
5. 같은 표현을 써보는 짧은 재작성 과제 1개.

문법 오류와 선택적인 스타일 제안을 구분한다. 원문을 덮어쓰지 않고 수정본·재작성본을 별도로 보관한다. AI 제안을 모두 오류로 확정하지 않으며 사용자가 ‘도움 됨 / 맞지 않음’으로 표시할 수 있다.

### 5.3 외부 공부 기록

- 외부 ChatGPT 대화나 작성한 글은 텍스트 붙여넣기로 가져온다. 역할 구분이 불명확하면 사용자가 원문 전체를 검토할 수 있도록 보존한다.
- 가져온 기록에는 원본 학습일, 선택적인 시간, 출처를 입력한다. 붙여넣은 순간부터 과거 학습 시간을 자동 추정하지 않는다.
- ChatGPT 공유 링크를 자동으로 읽거나 개인 계정에 접근하는 기능은 포함하지 않는다.

## 6. 스피킹과 쉐도잉

### 6.1 AI 단문 따라 읽기

흐름: **문장 선택 → 모범 음성 듣기 → 녹음 → 인식 결과 확인 → 피드백 → 다시 연습**.

- 초기 문장은 쉬운 일상 영어로 제공하며, 수준과 길이는 선택적으로 변경한다.
- 모범 음성은 AI 생성임을 표시한다. 생성된 문장과 음성은 재사용하여 같은 문장을 들을 때마다 다시 과금 호출하지 않는다.
- 녹음은 버튼을 누른 뒤에만 시작하며, 첫 사용에 브라우저 마이크 권한을 요청한다.
- 녹음 중 상태와 경과 시간을 크게 표시한다. 1회 최대 60초, 최대 10MiB로 제한하고 종료 전에 남은 시간을 안내한다.
- 녹음 후 듣기 / 다시 녹음 / 분석하기를 제공한다. 자동 업로드·분석은 기본값으로 켜지 않는다.

음성 생성과 파일 전사는 별도 제공 기능으로 연결한다. 구체 모델은 구현 시 지원 언어·형식·비용을 검증하여 서버 설정으로 선택한다. [OpenAI 음성 생성](https://developers.openai.com/api/docs/guides/text-to-speech), [음성 전사](https://developers.openai.com/api/docs/guides/speech-to-text)

### 6.2 유튜브 쉐도잉

- 사용자가 5~30초 구간을 지정한다. 긴 구간은 나눠 연습하도록 안내하되 강제로 새 자료를 만들지 않는다.
- 기본은 ‘듣기 → 영상 일시 정지 → 녹음’이다. 원본 소리가 마이크로 들어가는 것을 줄인다.
- 원본을 재생하며 동시에 녹음하는 모드는 후속 개선으로 두며, 이 경우 녹음 품질과 음원 혼입을 별도 검증한다.
- 타임스탬프 자막이 있으면 기준 문장으로 제안한다. 없으면 직접 문장을 입력하거나 녹음만 보관할 수 있다.
- 기준 문장이 없을 때는 전사와 자유 발화 표현 피드백만 제공한다. 원문 일치도는 표시하지 않는다.

### 6.3 피드백의 범위

- 원문과 음성 인식 문장의 단어 차이, 누락·추가 후보, 표현 설명을 제공한다.
- 인식 오류일 수 있음을 함께 안내하고 사용자가 인식 문장을 수정할 수 있게 한다. 원래 전사와 사용자 수정본을 모두 보존한다.
- 텍스트 비교 결과를 발음·억양 점수나 실제 발음 오류로 단정하지 않는다.
- 음질 불량, 무음, 너무 짧은 발화는 평가 대신 재녹음을 제안한다.
- 음소·강세·억양 평가는 별도 오디오 평가 방식과 검증 세트를 마련한 후 추가한다.

## 7. 자동 기록과 이어하기 규칙

### 7.1 두 종류의 단위

- **학습 공간(workspace)**: 하나의 영상, 라이팅 대화, 스피킹 과제를 이어가는 장소. 여러 날에 걸쳐 유지된다.
- **활동 세션(session)**: 특정 시간에 실제로 공부한 한 번의 활동. 한 공간에 여러 세션이 연결된다.
- 최근 위치·초안은 공간에 저장하고, 시간·학습일은 세션과 구간에 저장한다. 과거 세션의 시간을 이어하기로 다시 계산하지 않는다.

### 7.2 상태와 중단

세션 상태: `ACTIVE → PAUSED → ACTIVE`, `ACTIVE/PAUSED → ENDED`.

- 사용자가 플레이·입력·녹음·복습 답변 등 첫 활동을 하면 세션을 생성한다. 홈이나 자료를 열기만 한 것은 학습 시작이 아니다.
- 일시 정지 버튼, 화면 숨김·잠금, 활동 신호 단절 시 시간 집계를 멈춘다.
- 같은 공간에 30분 이내 복귀하면 일시 정지된 세션에서 이어갈 수 있다. 명시적 일시 정지는 ‘학습 재개’로, 자동 일시 정지는 새로운 유효 활동으로 재개한다. 그 이후에는 이전 세션을 마지막 확인 활동까지 종료하고 새 세션을 만든다.
- 마지막 서버 확인 이후 30분 동안 활동이 없으면 자동 종료 처리한다. 예약 정리와 다음 조회 시 정리를 멱등하게 수행한다.
- ‘학습 마치기’는 선택 동작이다. 이를 누르지 않아도 이미 확인된 활동 기록은 남는다.
- 탭 종료 이벤트만 믿지 않는다. 전송·저장은 활동 중 지속적으로 수행한다.

### 7.3 시간 계산

기본 단위는 초이며 화면에서만 분으로 표시한다. 기록 시간은 집중력이나 이해도를 측정한 값이 아니라 앱에서 관측한 활동 시간이다.

| 활동 | 인정하는 시간 | 제외하는 시간 |
| --- | --- | --- |
| 리스닝 | 화면이 보이고 플레이어가 재생 중이며 재생 위치가 진행한 실제 경과 시간 | 일시 정지, 버퍼링, 숨긴 화면, 탐색으로 건너뛴 구간 |
| 라이팅·대화 | 화면이 보이고 최근 60초 내 입력·전송·대화 읽기 스크롤이 있는 구간 | 60초 넘는 무활동, 숨긴 화면, 자동 AI 생성만 진행되는 시간 |
| 스피킹 | 모범 음성의 재생 시간, 사용자가 실제 녹음한 시간 | 마이크 허용 대기, 업로드·AI 처리 대기 |
| 표현 복습 | 카드가 열려 있고 최근 60초 내 답변·힌트·이동 활동이 있는 구간 | 단순히 복습 목록을 열어둔 시간 |

- 2배속으로 10분 길이의 내용을 5분 동안 들으면 학습 시간은 5분이다. 30초 구간을 3회 들으면 경과 시간 90초를 인정한다.
- 영상 위치의 합집합은 ‘접한 영상 구간’으로 별도 집계한다. 반복 시간과 혼동하지 않으며 시청률을 이해도로 표현하지 않는다.
- 진행 위치 변화가 없는 재생 상태나 관측 불가 구간은 학습 시간으로 확정하지 않는다. 광고와 같은 미디어 상태를 API로 완전히 식별할 수 있다고 보장하지 않는다.
- 같은 순간의 영상·대화·녹음 시간은 합집합으로 한 번만 계산한다. 유형 분류 우선순위는 녹음 → 직접 입력/복습 → 재생이며, 유형별 시간의 합은 총시간과 같아야 한다.
- 여러 탭·기기에서는 사용자당 하나의 계측 소유권만 허용한다. 다른 기기에서 시작하면 ‘이 기기에서 이어하기’를 명시적으로 선택해 소유권을 이전한다.
- 소유권은 60초 lease, 15초 heartbeat로 유지한다. 요청 순번과 이전 승인 구간을 서버에서 검사하고 중복 구간·비정상 미래 시각·과도한 시간 증가를 거부한다.
- 최종 계측 규칙은 버전으로 저장한다. 클라이언트가 보내는 누적 초를 그대로 신뢰하지 않는다.

### 7.4 자동 저장과 네트워크 오류

- 영상 위치는 5초마다 기기에, 15초 heartbeat와 일시 정지 시 서버에 저장한다.
- 초안은 입력 후 1초 이내 로컬 저장, 3초 debounce로 서버 저장한다. ‘저장 중 / 저장됨 / 기기에만 저장됨’을 구분한다.
- 로컬 데이터는 사용자 ID별로 분리한다. 로그아웃하면 해당 기기의 초안·음성 캐시를 지운다.
- 세션 이벤트는 고유 ID·순번으로 재전송하며 중복 합산하지 않는다. CAS 버전 충돌에서 다른 기기의 초안을 무조건 덮어쓰지 않는다.
- 60초를 넘는 연결 단절 시 자동 계측을 일시 정지한다. 미확인 시간을 보존하더라도 서버 확인 전 통계에 확정 반영하지 않는다.
- 강제 종료 직전 미전송 데이터는 복구하지 못할 수 있다. 마지막 저장 시각을 보여주고 복구된 내용과 확정 기록을 구분한다.
- 날짜 경계를 넘으면 세션 시작 시 저장한 시간대 기준 자정에서 구간을 나눈다. 시간대 설정 변경으로 과거 학습일을 재해석하지 않는다.

## 8. AI 학습 노트

### 8.1 생성 시점

- 첫 AI 사용 시 전송 대상(글·선택 자막·대화·분석 요청한 음성)과 자동 정리 여부를 안내한다.
- 자동 정리를 켠 사용자는 세션 종료 확정 후 비동기로 노트를 생성한다. 꺼두면 ‘정리하기’를 눌렀을 때만 생성한다.
- 세션당 내용 버전별 한 번을 기본으로 하며, 매 입력·heartbeat마다 AI를 호출하지 않는다.
- 종료 후 바로 다음 학습을 시작할 수 있다. 요약 실패가 원본 저장이나 다음 학습을 막지 않는다.

### 8.2 정리 결과

| 항목 | 내용 |
| --- | --- |
| 이번 학습 요약 | 근거가 있는 핵심 내용 최대 5개 |
| 단어·구문 | 표현, 뜻, 실제 사용 문맥, 예문 최대 10개 |
| 수정·어려움 | 원문과 제안, 이유, 사용자가 반복해서 연습한 항목 |
| 다음 연습 | 부담이 적은 활동 최대 3개 |
| 출처 | 메시지 ID, 글 버전, 자막 구간, 발화 시도 ID |

- 원문에서 나온 표현과 AI가 추가한 예문을 표시상 구분한다.
- 자막·메모·대화가 없으면 영상 내용 요약을 만들지 않는다. 시간만 기록된 세션은 활동 사실만 보여준다.
- 인용 위치는 서버가 실제 원본에 존재하는지 검증한다. 존재하지 않는 출처를 결과로 저장하지 않는다.
- 수정된 원문은 새 내용 버전을 만든다. 이전 노트는 ‘이전 내용 기준’으로 남기고 무단 덮어쓰지 않는다.
- 학습 자료 안의 명령문은 분석 대상 데이터로 취급한다. 시스템 지시나 외부 호출 권한으로 해석하지 않는다.

## 9. 표현 저장과 짧은 복습

### 9.1 표현함

- 자막·대화·첨삭 결과에서 표현을 선택해 한 번에 저장한다. 원문 문장과 원래 위치를 함께 보관한다.
- 직접 입력도 가능하다. 동일 표현은 기존 카드에 출처를 추가하도록 제안하며 자동 중복 병합하지 않는다.
- AI 요약의 모든 단어를 자동으로 복습 카드에 넣지 않는다. 사용자가 저장한 표현만 기본 복습 대상으로 삼는다.

### 9.2 오늘의 복습 3개

- 복습 예정일이 지난 카드 중 최대 3개를 기본 제시한다. 더 하기와 건너뛰기를 제공하며 밀린 개수를 경고하지 않는다.
- 정답을 먼저 보여주지 않고 뜻 떠올리기, 빈칸, 한국어 의도를 영어로 말하기/쓰기 중 하나로 제시한다.
- 답변 후 원문과 피드백을 보여주고 ‘어려움 / 보통 / 쉬움’을 선택한다. AI 판정은 사용자가 바꿀 수 있다.
- 초기 기본 간격은 1·3·7·14·30일을 제품 설정으로 사용한다. 어려움은 다음 날, 보통은 현재 간격 유지, 쉬움은 다음 단계로 이동한다. 이 숫자는 보편적인 최적 학습 주기라는 주장이 아니다.
- 복습 결과와 다음 예정일은 서버에 저장한다. 알림은 선택 사항이며 앱을 열면 바로 시작할 수 있어야 한다.

간격을 두고 기억에서 꺼내보는 활동을 설계 원칙으로 사용한다. 특정 사용자에게 효과나 성적 향상을 보장하지 않는다. [Spacing and retrieval practice guide](https://www.edresearch.edu.au/guides-resources/practice-guides/spacing-and-retrieval-practice-guide-full-publication)

### 9.3 내 문장으로 사용하기와 변화 비교

- 저장한 표현으로 내 상황의 문장을 쓰거나 말한다. 듣기 → 따라 읽기 → 내 문장 만들기를 선택적으로 연결한다.
- 반복 실수 후보는 서로 다른 과제에서 사용자가 확인한 유사 수정이 3회 이상 있을 때 제시한다. 사용자가 해제할 수 있다.
- 변화 비교는 같은 기준 문장이나 같은 과제의 원문·녹음과 날짜를 나란히 보여준다. 서로 다른 난이도의 결과를 단일 향상 점수로 합치지 않는다.

## 10. 기록과 통계

- 영어학습 기록 목록: 날짜, 유형, 자료, 활동 시간, AI 노트 상태. 언어·유형·자료로 필터링한다.
- 상세: 원본, 대화, 작성본/수정본, 발화 시도, 표현, AI 노트, 시간 구간을 확인한다.
- 관측 시간이 잘못된 경우 사용자가 정정 사유와 시간을 입력한다. 원래 측정과 정정 이력을 남기고 유효 정정만 집계한다.
- 영어학습 시간은 중복을 제거한 자동 계측과 수동 정정을 구분한다. 기존 도서 수동 시간은 절대 시각이 없어 영어학습 시간과 완전한 중복 제거가 불가능함을 집계 설명에 명시한다.
- 전체 ‘기록된 시간’은 기존 도서 수동 시간 + 유효 영어학습 시간이다. ‘순수 비중복 집중 시간’으로 이름 붙이지 않는다.
- 활동일은 도서의 유효 학습·복습 기록 또는 영어학습의 인정 시간/사용자 작성·발화·복습 제출이 있는 날짜의 합집합이다. 링크 저장, 자료 열기, AI 응답만 생성된 날은 제외한다.
- 페이지, 녹음 횟수, 작성 단어 수, 복습 개수를 한 단위로 합산하지 않는다. 기록이 적으면 언어 능력 변화나 이해도를 추정하지 않는다.

## 11. 데이터 모델 제안

모든 개인 테이블은 `user_id`, 생성/수정 시각을 가지며 사용자 소유권을 RLS와 복합 FK로 강제한다. 아래는 신규 모델이며 실제 SQL migration은 단계별 구현에서 작성한다.

| 테이블 | 주요 데이터 / 관계 |
| --- | --- |
| `learning_items` | 유형 YOUTUBE/WRITING/SPEAKING/IMPORTED_TEXT, 제목, 언어, 영상 ID, 원문, 보관 상태 |
| `youtube_connections` | 사용자별 연결 채널, 승인 범위, 만료/철회 상태; 암호화된 토큰은 서버 전용 저장 영역에서 관리 |
| `learning_workspaces` | 자료 ID, 대화 ID, 최근 위치, 초안 버전, 최근 사용 시각 |
| `learning_sessions` | 공간 ID, 상태, 시작/종료, 시간대, 계측 버전, 선택한 상황 |
| `learning_activity_segments` | 세션, 이벤트 ID, 순번, UTC 구간, 학습일, 활동 유형, 확정 상태 |
| `learning_session_leases` | 사용자별 활성 계측 소유자, 세대 번호, 만료 시각 |
| `learning_time_corrections` | 원 세션/학습일, 대체 시간, 사유, 무효화 관계 |
| `learning_transcript_segments` | 자료, 원문 버전, 시작/종료 시각(선택), 텍스트, 사용자 제공 출처 |
| `learning_messages` | 대화/세션, 사용자 메시지 ID, 역할, 본문, 응답 상태, 작성본 관계 |
| `speaking_attempts` | 기준 문장/영상 구간, 비공개 녹음 경로, 원 전사·수정 전사, 처리 상태 |
| `learning_ai_jobs` | 대상·종류·입력 해시, 상태, lease, 시도 횟수, 출력, 모델·사용량 |
| `learning_expressions` | 표현·뜻·언어·원문 출처 목록, 보관 여부 |
| `learning_review_attempts` | 표현, 문제 종류, 사용자 답변, 피드백, 자기 평가 |
| `learning_review_schedule` | 표현별 현재 단계, 다음 학습일, 알고리즘 버전 |

`learning_ai_jobs`는 기존 작업 큐의 claim/lease/finish 패턴을 재사용하되 도서 전용 FK와 분리한다. 대화 생성, 음성 전사, 음성 생성, 첨삭, 요약의 결과가 각각 원본과 연결되어 추적 가능해야 한다.

## 12. API 계약 초안

모든 개인 API는 인증 필요, `no-store`, 소유하지 않은 대상은 404로 응답한다. 생성 요청에는 멱등성 키, 변경 요청에는 버전을 사용한다. 아래 경로는 구현 기준 초안이다.

| API | 역할 |
| --- | --- |
| `GET/POST /api/learning/items` | 자료 목록 / 링크·텍스트 등록 |
| `POST /api/integrations/youtube/connect` | 사용자 요청으로 OAuth 시작, state 생성 |
| `GET /api/integrations/youtube/callback` | 인증 코드·state 검증 후 계정 연결 완료 |
| `GET/DELETE /api/integrations/youtube` | 연결 상태 조회 / 연결 해제 |
| `GET /api/integrations/youtube/playlists` | 연결 계정의 접근 가능한 재생목록 조회 |
| `GET /api/integrations/youtube/playlists/{id}/items` | 재생목록 영상 조회, 선택 항목은 기존 자료 등록 API로 저장 |
| `GET /api/integrations/youtube/subscriptions` | 연결 계정의 구독 채널 조회 |
| `GET /api/integrations/youtube/channels/{id}/videos` | 선택 채널의 접근 가능한 공개 영상 조회 |
| `PATCH/DELETE /api/learning/items/{id}` | 제목·보관 상태 수정 / 자료 삭제 |
| `GET /api/learning/home` | 이어하기, 저장 영상, 복습 후보 |
| `GET/PATCH /api/learning/workspaces/{id}` | 공간 조회 / 초안·위치 버전 저장 |
| `POST /api/learning/sessions` | 활동 시작 또는 일시 정지 세션 재개 |
| `POST /api/learning/sessions/{id}/events` | 구간·heartbeat·일시 정지·종료를 순번대로 적용 |
| `POST /api/learning/sessions/{id}/takeover` | 다른 기기의 활성 계측 소유권 이전 |
| `POST /api/learning/sessions/{id}/time-corrections` | 측정 시간 정정 |
| `GET/POST /api/learning/workspaces/{id}/messages` | 대화 조회 / 사용자 메시지 저장 및 AI 생성 접수 |
| `POST /api/learning/messages/{id}/retry` | 실패한 응답 재시도 |
| `POST /api/learning/items/{id}/transcript` | 사용자 제공 자막 저장 |
| `POST /api/learning/speaking-attempts` | 업로드 허가와 발화 시도 생성 |
| `POST /api/learning/speaking-attempts/{id}/analyze` | 업로드 검증 후 전사·피드백 요청 |
| `POST /api/learning/sessions/{id}/summary` | 동일 내용 결과 재사용 또는 정리 접수 |
| `GET /api/learning/jobs/{id}` | 작업 상태·검증된 결과 조회 |
| `POST /api/learning/jobs/{id}/cancel` | 생성 중단 요청 |
| `GET/POST /api/learning/expressions` | 표현 조회·저장 |
| `GET /api/learning/reviews` | 복습 대상 조회 |
| `POST /api/learning/reviews/{expressionId}/attempts` | 답변과 자기 평가 저장 |
| `GET /api/learning/statistics` | 영어학습 지표 조회; 기존 통계와 표시 계층에서 통합 |

- 400 입력 오류, 401 인증 만료, 404 대상 없음, 409 버전/소유권 충돌, 413 용량 초과, 429 한도 초과, 503 제공자/기능 사용 불가.
- 작업 접수는 202, 저장된 결과 재사용은 200. 5xx나 타임아웃 뒤에는 같은 키로 결과를 조회·재시도한다.
- AI 응답 스트리밍은 서버가 저장하는 결과를 전달하는 방식으로 설계한다. 연결이 끊기면 저장된 메시지·작업 상태로 복구한다.
- 생성 중단은 최선 노력이며 이미 처리된 제공자 사용량까지 취소된다고 보장하지 않는다.

## 13. 보안·음성 보관·비용

- OpenAI 키는 서버/Worker에만 둔다. 브라우저에는 서비스 역할 키나 공급자 API 키를 전달하지 않는다.
- 현재 키가 Worker에만 있는 구조를 유지한다. 대화 스트리밍을 위해 Worker API를 추가할 때 인증과 작업 소유권 검사를 필수로 한다.
- 녹음은 private Storage에 저장하고 짧은 만료의 서명 URL로 접근한다. MIME/실제 형식·크기·길이를 서버가 검증한다.
- 기본 음성 보관 기간은 30일을 제안한다. 사용자가 ‘계속 보관’을 선택한 녹음은 직접 삭제 전까지 유지한다. 삭제한 음성의 전사·피드백은 별도 기록으로 남는다는 점을 표시한다.
- 자료 삭제 시 연결 대화·초안·녹음·AI 결과·표현 출처·통계 영향 범위를 먼저 보여준다. 보관은 집계 유지, 삭제는 집계 제외다.
- 진행 중 작업 취소와 Storage 삭제를 포함한 재시도 가능한 삭제 작업으로 구현한다. 삭제된 원본을 늦게 도착한 AI 결과가 되살리지 못하도록 한다.
- 첫 녹음은 마이크 권한, ‘분석하기’는 외부 음성 전송에 대한 명시적 동작이다. AI와 무관한 기록 저장은 제공자 장애나 동의 거절에도 가능하다.
- 입력 제한 기본값: 메시지 8,000자, AI 한 요청의 선택 문맥 20,000자, 녹음 60초/10MiB. 문맥이 넘으면 처리 범위를 명시하고 전체를 분석한 것처럼 표시하지 않는다.
- 사용자별 초기 기본 한도: 진행 중 AI 작업 3개, 분당 접수 10회, 일일 대화·첨삭 100회, 음성 분석 30회, 요약 20회. 운영 설정에서 조절하며 실제 비용 상한과는 구분한다.
- 모델·토큰·오디오 사용량을 작업별로 저장한다. 비용 추정은 적용한 단가 버전과 함께 표시하며 결제 청구액과 구분한다.
- 정확한 과금 상한과 경보는 제공자의 지원 기능을 별도 검증한다. 응답 재시도나 Worker 장애로 외부 호출이 중복될 가능성을 비용 계산에서 고려한다.

## 14. 모바일·PWA와 접근성

- 현재 웹앱에서 구현한다. 설치형 PWA는 영어학습 기본 동작 이후 추가한다.
- HTTPS와 지원 브라우저에서 마이크 기능을 제공한다. 권한 거절·미지원에서는 텍스트 입력으로 학습을 계속한다.
- iOS Safari와 Android Chrome에서 실제 키보드, 권한, 녹음 포맷, 탭 전환, 전화 등 중단 상황을 확인한다.
- 브라우저 자동 재생 정책을 우회하지 않는다. 사용자 재생 동작이 필요한 경우 즉시 안내한다.
- 화면 숨김 시 계측과 녹음을 안전하게 멈춘다. 백그라운드 시청 시간을 확정 기록하지 않는다.
- 오프라인에서는 이미 저장한 초안·텍스트 확인 및 편집까지만 초기 지원한다. 유튜브·AI·전사는 연결 복구 후 가능하다.
- Service Worker에 인증 응답·개인 대화·음성·서명 URL을 공용 캐시하지 않는다. 설치·업데이트 안내가 입력 중인 초안을 지우지 않도록 한다.
- 주요 버튼 최소 44px, 키보드 탐색·포커스 복원·상태 읽기 지원. 녹음 결과를 색상이나 음성만으로 전달하지 않는다.

## 15. 단계별 구현 범위

기존 Phase 0~8과 혼동하지 않도록 이 확장은 LR 단계로 표기한다.

| 단계 | 구현 내용 | 완료 조건 |
| --- | --- | --- |
| LR1 | 공통 공간·세션·초안·자동 저장·타이머·일시 정지/재개/종료·AI 라이팅·첫 노트 | 입력부터 중단·이어하기·기록 확인까지 실제 흐름 동작 |
| LR2 | 유튜브 링크 모음·계정 연결·재생목록/구독 채널 선택·플레이어·PaceOn 시청 이력·구간 반복·자막 수동 입력·영상 질문 | 시간 규칙·이전 위치 복원·OAuth 만료/철회 검증; Premium과 전체 시청 기록의 제한 명시 |
| LR3 | AI 단문 음성·녹음·전사·유튜브 쉐도잉·발화 기록 | 두 스피킹 방식이 실제 모바일에서 동작하고 텍스트 비교 한계를 표시 |
| LR4 | 표현 저장·오늘의 복습 3개·내 문장 만들기·통합 통계 | 원문에서 복습까지 연결되고 중복 집계가 없음 |
| LR5 | 상황별 추천·실수 모음·변화 비교·PWA | 추천을 건너뛰어도 바로 학습 가능, 설치 후 이어하기 검증 |

각 단계는 독립적으로 사용할 수 있어야 한다. LR1 완료를 전체 기능 완료로 표현하지 않는다. 단계별 상세 구현 계획과 DB migration은 해당 단계 착수 시 이 명세를 기준으로 작성한다.

| A23 | Premium 계정으로 브라우저별 임베드 재생 | 실제 광고 여부 관측; OAuth 성공만으로 무광고 표시 금지 |

단위 테스트는 시간 구간 합산, lease/순번, 날짜 분할, 링크 정규화, 복습 간격, AI 출력 검증을 다룬다. DB 테스트는 RLS·복합 FK·멱등성·삭제 경합을 확인한다. 통합 테스트는 실제 Auth/DB/Storage/Worker에 테스트 제공자를 연결하고, 소량의 실제 AI 호출 및 실제 모바일 검증은 별도 실행한다.

초기 사용성 목표: 로그인된 사용자가 이어하기를 찾는 데 1탭, 자료 선택에서 활동 시작까지 최대 2탭(최초 권한 요청 제외). AI 응답 속도는 제공자 지연과 분리해서 측정하며 이를 학습 시작의 선행 조건으로 만들지 않는다.

## 17. 구현 착수 시 확정할 운영 항목

기능 요구와 분리해 다음 항목은 각 단계 시작 시 확인한다. 확인되지 않은 기능을 이미 지원하는 것처럼 표시하지 않는다.

- LR1: 대화 생성 Worker의 스트리밍 전달 방식, 선택 모델과 요청별 출력 한도, 운영 비용 경보.
- LR2: 영상 메타데이터 조회 방식과 키/쿼터, Google OAuth 앱 등록·동의 화면·필요한 검증과 배포 callback URL, 토큰 암호화·철회 및 API 데이터 보관 정책. 자막은 사용자 입력 방식으로 시작한다. Premium은 실제 계정과 브라우저별 임베드 환경에서 검증한다.
- LR3: 음성 모델·브라우저별 녹음 포맷 검증, 보관 설정·정리 작업, 실제 모바일 권한 테스트.
- LR5: 배포 HTTPS/도메인, PWA 캐시·업데이트 정책, 알림을 추가할지 여부.

이 문서의 제한값과 보관·복습 기본값은 구현 가능한 초깃값 제안이다. 사용성 확인 후 설정으로 조정하며, 학습 효과나 공급자 지원을 검증 없이 보장하는 수치로 취급하지 않는다.
