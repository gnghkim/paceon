# Phase 8 — 학습 통계

메뉴의 **통계**에서 책과 PDF에 기록한 학습을 기간별로 확인한다. 최근 7·30·90일 또는 최대 366일의 시작일·종료일을 선택할 수 있다. 기본값은 오늘을 포함한 최근 30일이다.

## 지표

| 표시 | 계산 기준 |
| --- | --- |
| 새로 학습한 분량 | 유효한 새 학습 기록의 페이지 합계. 자료 등록 시 이미 읽은 페이지는 제외 |
| 복습한 분량 | 유효한 복습 기록의 페이지 합계. 같은 페이지를 반복 복습한 분량도 포함 |
| 기록된 시간 | 새 학습·복습에 직접 입력한 분만 합산 |
| 학습한 날 | 선택 기간에 유효한 학습·복습 기록이 있는 날짜 수. 여러 자료를 읽은 날도 1일 |
| 시간 입력·미입력 | 0분 입력과 시간 미입력을 구분해 건수 표시 |
| 기간 내 기록 속도 | 0분보다 큰 시간이 입력된 새 학습의 총시간 ÷ 해당 기록의 총페이지. 복습·0분·미입력 제외. 표본이 없으면 계산하지 않음 |

정정 또는 무효 처리된 원래 기록은 집계하지 않는다. 무효 처리가 조회 기간 이후에 발생했어도 원래 기록을 제외하며, 대체 기록은 정정된 학습일에 반영한다. 날짜별 표와 자료별 합계에도 같은 규칙을 적용한다. 기록 속도는 해당 기간의 관측값이며 일정 계산에 사용되는 속도 추정치와 구분한다.

오늘 날짜는 저장한 사용자 시간대 기준이며 미설정이면 Asia/Seoul이다. 과거 기록은 저장된 학습일을 그대로 사용하므로 시간대를 변경해도 과거 날짜를 재해석하지 않는다. 이해도·계획 수행률·예상 시간을 실제 학습 실적으로 표시하지 않는다.

## API와 데이터 경계

`GET /api/statistics`는 로그인 Bearer 토큰이 필요하다. 선택 매개변수는 `from`, `to`(YYYY-MM-DD), `resourceId`(UUID)다. 날짜는 양 끝을 포함하고 종료일은 오늘까지다. 중복·알 수 없는 매개변수와 잘못된 날짜는 400, 다른 사용자의 자료는 404다.

응답은 `{from,to,today,timezone,summary,days,resources}`이며 일별 항목에는 기록이 없는 날도 포함한다. 학습 메모와 원본 파일·AI 입력은 포함하지 않는다. 모든 조회는 사용자 토큰과 소유자 필터/RLS를 사용하고 `no-store`로 응답한다. 새 테이블이나 예약 작업 없이 기존 기록을 읽으며 계획·진도·일정을 변경하지 않는다.

정정의 정확성을 위해 선택 기간 밖 기록까지 읽어 무효 관계를 먼저 해소한다. 기존 REST 조회 한도에 따라 테이블당 20,000행에 도달하면 불완전한 합계를 표시하는 대신 조회 실패를 알린다. 잘못된 학습 또는 복습 페이지 범위도 조용히 합산하지 않는다. 장기 대용량 집계를 위한 DB 집계·캐시는 후속 범위다.

- `pnpm test`: 날짜 범위·등록 진도 제외·복습/시간 미입력·정정·소유권·응답 비공개 필드·페이지네이션과 상한 검사.
- `pnpm test:statistics:integration`: 빌드 후 실행. 실제 로컬 Auth·프로덕션 웹·DB에서 자료와 계획·학습·정정을 생성하고 통계와 사용자 격리를 확인한다. 임시 계정만 정리하며 기존 관리자 계정은 변경하지 않는다.
- `pnpm typecheck`, `pnpm lint`, `pnpm build`.
