# Changelog

사용자 체감 변경과 구조적으로 의미 있는 변경만 기록한다. 없는 카테고리는 생략한다.

## 2026-10-09

### Added
- 독서 기록 창에서 읽기 시작, 집중 화면에 지난번 읽은 쪽과 오늘 일정 (#33)
- 문장 기록: 읽는 도중(타이머 띠·집중 화면)이나 도서 상세에서 문장을 쪽과 함께 남기기 (#34)
- 완료 기록 카드: 책을 다 읽거나 교재·강의를 마치면 시작일·완료일·실제 읽은 날·하루 평균·기록한 시간·목표 대비를 완료 순간과 상세 화면에 보여 주기

### Changed
- 집중 화면의 상태와 책 제목 글자 크기 (#33)

## 2026-10-07

### Added
