# 표현 저장과 오늘의 복습

영어학습에서 만난 표현을 복습함에 넣고, 간격을 두고 다시 꺼내 본다. 간격을 두고 기억에서 꺼내 보는 연습을 설계 원칙으로 삼는다. 특정 사용자에게 효과나 성적 향상을 보장하지 않는다. [Spacing and retrieval practice guide](https://www.edresearch.edu.au/guides-resources/practice-guides/spacing-and-retrieval-practice-guide-full-publication)

## 저장

AI 피드백의 **기억할 표현** 아래 **복습함에 넣기**를 누르면 그 표현만 저장된다. AI가 고른 표현을 자동으로 넣지 않는다. 사용자가 고른 것만 복습 대상이 된다.

단어를 직접 적어 넣는 길은 [단어장](WORD_BOOK.md)에 있다. 공부하는 도중에는 학습 화면의 **단어 담기**로 그 자리에서 담는다. 두 길 모두 같은 표에 쌓인다. 단어장에서 뜻 없이 넣은 카드는 AI가 뜻을 채울 때까지 복습에 나오지 않는다. 물어볼 답이 없기 때문이다.

같은 표현을 다시 저장하면 **이미 저장한 표현이에요**라고 알린다. 기존 카드와 합치지 않는다. 표현을 가져온 학습 공간을 함께 기록하며, 그 공간을 지워도 표현은 남는다.

## 복습

**오늘** 화면의 영어학습 카드와 영어학습 화면 위쪽에 복습할 개수가 뜬다. 없으면 자리를 차지하지 않는다. `/learn/review`에서 한 번에 세 개를 묻는다.

- 뜻을 먼저 보여 주지 않는다. 표현만 보여 주고 떠올리게 한 뒤 **뜻 확인하기**로 연다.
- 확인한 뒤 **어려웠어요 / 보통이에요 / 쉬웠어요** 중 하나를 고른다.
- **건너뛰기**는 예정일을 그대로 두고 다음 카드로 넘어간다. **복습함에서 빼기**는 카드를 지운다.
- 세 개를 마치고 더 남아 있으면 **N개 더 하기**가 나온다.
- 밀린 개수를 세어 보여 주지 않는다. 밀렸다고 경고하지도 않는다.

## 간격

기본 간격은 **1·3·7·14·30일**이다. 제품 기본값이며 누구에게나 최적인 주기라는 주장이 아니다.

| 답 | 다음 |
| --- | --- |
| 어려웠어요 | 첫 간격으로 돌아가 내일 다시 |
| 보통이에요 | 지금 간격을 유지 |
| 쉬웠어요 | 다음 간격으로. 마지막 간격에서는 그대로 |

막 저장한 표현은 저장한 날이 아니라 **다음 날부터** 묻는다. 간격 계산은 웹에서 하고, DB는 결과가 표 안에 있는지와 예정일이 과거로 가지 않는지만 확인한다.

## 아직 아닌 것

- **복습 시간은 학습 시간에 들어가지 않는다.** 타이머는 학습 공간(`learning_sessions`)에 묶여 있는데 복습은 공간을 넘나든다. 스펙 §7.3을 지키려면 세션 모델을 손봐야 하므로 후속 작업으로 둔다.
- 스펙 §9.1의 "기존 카드에 출처 추가 제안", §9.2의 빈칸·한국어 의도 말하기 같은 다른 출제 방식, §9.3의 내 문장 만들기와 변화 비교는 범위 밖이다.
- 자막과 대화에서 직접 선택해 저장하는 것은 아직 없다.
